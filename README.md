# Serious Game ICOPE Audition

### Description du projet

Ce projet vise à développer un environnement 2D interactif permettant d'apprendre et de comprendre l'algorithme de détection des troubles auditifs chez les personnes agées. 
Il est conçu pour former le personnel médical à l'identification et à la prise en charge de ces problèmatiques.

Ce serious game est réalisé dans le cadre d'un projet tutoré par des étudiants en Master 1 AMINJ de l'INU Champollion, en collaboration avec le CHU de Toulouse, durant l'année universitaire 2023-2024.
